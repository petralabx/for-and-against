# Keyword snapshots

Dated Jungle Scout (or equivalent) exports live in `YYYY-MM/` folders. Treat each folder as a point-in-time archive — never as current SEO truth beyond its date.

The 2026-07 export set (body wash, shampoo, conditioner, lotion — retail/refill-pouch/gallon variants) is in `data/keywords/2026-07/`, trimmed to the top 140 keywords per category by search volume. See that folder's README for methodology.
